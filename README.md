# Hey, I'm Mimi 👋

I'm a Computer Science graduate and Data Scientist who enjoys learning by **building, experimenting, breaking things, and going down way too many rabbit holes.**

### 🚀 What I'm exploring

Currently working across **AI, agentic systems, data science, and software engineering** — with a particular interest in understanding how systems actually work under the hood.

Some of the areas I'm exploring:

* 🤖 **AI & Agentic Systems** — AI agents, multi-agent architectures, RAG, routing, tool use, and LLM-powered applications
* 🧠 **Machine Learning & Data Science** — EDA, clustering, dimensionality reduction, statistics, and predictive modeling
* 🔎 **RAG & Search** — embeddings, vector search, metadata, indexing, Azure AI Search, and retrieval pipelines
* ☁️ **Data & Cloud Engineering** — Azure, Databricks, Snowflake, ADLS, ADF, Delta Lake, and data pipelines
* 🐍 **Python & Data** — Pandas, NumPy, Polars, scikit-learn, APIs, and automation
* 🌐 **Software Development** — React, Node.js, FastAPI, SQL, REST APIs, authentication, and application architecture
* 🧪 **Simulation & AI** — Agent-based modeling, Mesa, Mesa-Frames, and simulation-driven experimentation

### 🧪 What's on this profile

A mix of:

* 🧠 Learning experiments
* 🤖 AI & agent projects
* 📊 Data science and ML work
* 🔬 Research-driven explorations
* 🌐 Full-stack and application builds
* ☁️ Data engineering experiments
* 💡 Random ideas that somehow became projects
* 🚧 Work-in-progress builds

Not everything here is polished — and that's intentional.

Some repositories are experiments. Some are learning exercises. Some are attempts to understand a concept by actually building it. And occasionally, one of those experiments turns into something much bigger.

### 🌱 How I learn

**Learn → Build → Break → Debug → Understand → Improve → Repeat.**

I believe the fastest way to understand technology is to **build something with it** — then figure out why it broke.

This GitHub is essentially a collection of those rabbit holes. 🐇
